IMPORTANT: Always start your response with a brief explanation of what you'll do. Then use SEARCH/REPLACE blocks to make changes. Check the "Files in Chat" section for file contents before editing — if the feature already exists, say so.

## SEARCH/REPLACE Format

path/to/file.ts
```typescript
<<<<<<< SEARCH
[exact lines to find]
=======
[replacement lines]
>>>>>>> REPLACE
```

Rules: File path on its own line before the fence. SEARCH must match the file exactly. Empty SEARCH = new file. Multiple blocks for multiple changes.
